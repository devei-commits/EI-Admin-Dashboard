# Quick Start Guide: Order Hub Workflow

## 🚀 Getting Started in 5 Minutes

### 1. Access Order Hub
```
Sidebar → Order Hub → Orders Tracker Tab (default)
```

### 2. Understand the Dashboard
- **Top Section**: Statistics showing orders in each stage
- **Search Bar**: Find orders by Order No, SKU, or Item Name
- **Order Cards**: Visual representation of each order's progress

### 3. View an Order's Progress
Each order card shows:
```
[Order #] [Type Badge]        Stage X/6
[Item Name]                   [Stage Name]

[Progress Bar: ✓ ✓ ⚙ ○ ○ ○]

[Order Date] [Est. Date] [Rate] [Status]
```

### 4. Move Order to Next Stage
```
1. Find the order in Orders Tracker
2. Click "[Move to Stage X]" button
3. Order automatically progresses
4. Progress bar updates
5. Card shows new stage
```

### 5. Filter Orders (Optional)
```
Use dropdown: "All Stages" → Select specific stage
Or Search: Type Order No / SKU / Item Name
```

## 🎯 Common Tasks

### Task: Find an Order
```
1. Click search bar
2. Type: Order No (e.g., "SO-02907") 
        OR SKU (e.g., "SK2201")
        OR Item (e.g., "CORREXION")
3. See matching orders
4. Filter by stage if needed
```

### Task: Check Order Status
```
1. Go to Orders Tracker
2. Find order in list
3. Read:
   - Current stage indicator: "Stage X/6"
   - Progress bar: Shows completed (✓), current (⚙), pending (○)
   - Status field: Shows order status (UNDER REVIEW, etc.)
```

### Task: Complete a Stage
```
1. Go to stage tab (Orders Review, Purchase Plan, etc.)
2. Do required work:
   - Fill in required fields
   - Validate information
   - Update statuses
3. Return to Orders Tracker
4. Click "Move to Stage X" button
5. Order progresses automatically
```

### Task: Track Multiple Orders
```
1. Go to Orders Tracker
2. See all 60+ orders with current stages
3. Statistics at top shows counts per stage
4. Scroll through cards to see overall progress
5. Use filter to focus on specific stage
```

### Task: Export/Print Order List
```
1. Filter to desired stage (optional)
2. Take screenshot (built-in screenshot tool)
   OR Copy order numbers for reporting
```

## 💡 Pro Tips

### Tip 1: Use Search First
```
If you don't remember the exact order number,
search for SKU or part of item name
```

### Tip 2: Filter by Stage
```
To focus on orders needing your attention,
filter by current stage
```

### Tip 3: Statistics Dashboard
```
Check top statistics for quick overview:
- Which stages are busiest
- Where bottlenecks might be
- Overall order distribution
```

### Tip 4: Progress Icons
```
✓ = Done (Emerald - Completed)
⚙ = Working (Blue - In Progress)
○ = Waiting (Gray - Pending)
```

### Tip 5: Sort by Stage
```
If you work on specific stage,
use filter to show only that stage,
then scroll through orders
```

## 🔍 Troubleshooting

**Q: Order doesn't show in Orders Tracker**
```
A: 1. Check search filter
   2. Check stage filter
   3. Try clearing all filters
   4. Refresh page (F5)
```

**Q: Can't move order to next stage**
```
A: 1. Verify all stage requirements complete
   2. Check if order is already closed
   3. Look for error message
   4. Try refreshing page
```

**Q: Progress bar not updating**
```
A: 1. Click "Move" button again
   2. Refresh page to sync
   3. Close and reopen Orders Tracker tab
```

**Q: How do I go back a stage?**
```
A: Currently stages are forward-only
   Contact admin to request backward progression
```

## 🎯 Your First Order Progression

   - Move to Stage 4
